## Прогнано в третьей сессии

1. **Сборка iOS — PASS.** `BUILD SUCCEEDED`, Xcode 26.6, `ARCHS=arm64`.
   `bindCurrentDevice()` и вызовы из `Session.activate()` / `Session.signIn(paired:)`
   компилируются, методы FFI на месте. Попутно: со стандартным
   `generic/platform=iOS Simulator` сборка падает на линковке `x86_64` —
   в `SmCoreFFI.xcframework` только arm64-слайсы. Swift при этом компилируется
   целиком; для CI это значит, что `ios.yml` соберётся только на arm64-macOS.

2. **Миграция `totp_pending_secret` — PASS, 19 из 19.** Проверена не на свежей
   базе, а на настоящей доаудитной: поднят сервер из `a8e1804`, заведены три
   состояния (2FA включена / настройка оборвана / 2FA не трогали), затем на той
   же базе запущен новый сервер. Колонка добавляется, включённая 2FA
   продолжает работать, оборванная настройка доводится compat-веткой.

3. **Сырой WS-хендшейк — PASS, 7 из 7.** Старый `?token=` принимается
   (обратная совместимость цела), мусор/истёкшая сессия/пустые параметры
   отвергаются, билет одноразовый. Побочно: отказы приходят как HTTP 403 до
   апгрейда, а не как WS-close 1008 — см. Info в отчёте.

4. **Таблица веток — заполнена.** Клон оказался shallow, история дотянута.
   Гипотеза №1 **подтверждена**: на `main` в `android/` слова «ratchet» нет ни
   разу, DM идёт через crypto_box.

Плюс повторный прогон всех серверных и веб-наборов на **мигрированной** базе —
всё зелёное.

5. **CI в GitHub Actions — ПРОГНАН.** Ветка запушена, `ci.yml` отработал:
   `Rust core + protocol vectors`, `Web (wire + security)`,
   `Server API + security regressions` — **все три зелёные** (2m53s).
   Шаг «Открыть регистрацию» сработал, `403 approval_required` не возникло.

   Заодно выяснилось, что второй workflow, `iOS build`, не проходил **ни разу**
   — на `a8e1804` тоже. Три причины, все починены, теперь **зелёный** (13m03s):
   CI неоткуда не брал `AETHER/Core/Secrets.swift` (он в `.gitignore`, локально
   есть только у владельца); не фиксировался `ARCHS`, из-за чего линковка
   искала несуществующий `x86_64`-слайс ядра; и ошибка компиляции, видимая
   только на Xcode 26.1.1 из CI, но не на локальном 26.6.

   Отсюда вывод на будущее: **локальная сборка iOS не доказывает, что соберётся
   CI**. Версии Xcode разные, `Secrets.swift` есть только локально — и именно
   поэтому сломанный workflow годами никого не беспокоил.
