# AETHER — задачи

## Отложено

### Анимации закреплённых чатов (iOS)
Сейчас закрепление/открепление использует нативный переезд строки в List
(одна коллекция `ordered`, соседи разъезжаются) — как в Telegram, чисто.
Что можно доработать позже:
- Более выразительный «взлёт» закрепа наверх (мягкая пружина/акцент),
  БЕЗ оверлейных летающих копий (пробовали — источник багов: смещённый
  кадр из-под свайпа, наложения, улёт за экран). Только в рамках List.
- Возможно — лёгкая подсветка/хайлайт строки в момент пина.
- Проверять на живом устройстве, не только в симуляторе.
